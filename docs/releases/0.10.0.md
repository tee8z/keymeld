# KeyMeld v0.10.0

The gateway now gives every request an id and writes one request line per request, and the configured logging settings take effect. The SDK gains an optional per-request header hook.

## Changes

- Give each gateway request an id. A valid `X-Request-Id` from a trusted proxy is kept; otherwise the gateway makes a UUIDv7. The id is echoed in the `X-Request-Id` response header and recorded on the request span, so every line logged while the request is handled carries it.
- Write one `http` line per request after the response: request id, the caller's parent request id (`X-Parent-Request-Id`), session id (`X-Session-Id`), client address, method, route template, status and duration. Query strings, bodies and signatures are never logged. Health, metrics, static assets and the operator dashboard's polling fragments are skipped.
- The client address comes from the existing `rate_limit.client_ip_header` and `trusted_proxy_ips` settings, the same rules admission control uses.
- CORS allows `X-Parent-Request-Id` and `X-Session-Id` and exposes `X-Request-Id`.
- Fix logging being initialised twice at start-up. The configured format and level were ignored and the defaults always applied; now the configured settings win. The shipped `production.yaml` and Helm values now ask for compact text, which is what the gateway wrote before this fix.
- Add `KeyMeldClientBuilder::request_headers`, an optional provider called for every SDK request, so applications can attach per-request headers such as `X-Parent-Request-Id`. The change is additive.

## Upgrade

No route, wire format or sealed state changed.
Deployments whose logging config asks for JSON (`format: json`, `enable_json: true`) now get JSON. Set `format: compact` and `enable_json: false` to keep text output.
To log the real client address behind a proxy, set `rate_limit.client_ip_header` to the header your proxy sets and list the proxy in `trusted_proxy_ips`.

```toml
keymeld-sdk = { git = "https://github.com/tee8z/keymeld", tag = "v0.10.0", features = ["client", "dlctix"] }
```
