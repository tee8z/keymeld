# Keymeld 0.10.1

Enclaves retain command identifiers and payload digests for replay checks instead
of retaining completed command payloads. Large signing requests no longer remain
in session history after processing. Replay and authorization checks are unchanged.

Custom enclaves must rebuild against this release to receive the fix. Updating
the gateway alone does not replace a custom Coordinator enclave.

Validation: enclave unit and KMS integration tests, Clippy, and the release
end-to-end suite. The memory regression submits 96 MiB of command payloads and
checks that retained command metadata remains below 4 KiB.
