# Keymeld 0.10.6

The gateway bundles SQLite 3.51.3 instead of 3.46.0, through sqlx 0.9.0 and libsqlite3-sys 0.37.0.
3.46.0 has a rare write-ahead-log bug that can corrupt a database; 3.50.2 through 3.51.3 also fix further WAL and locking issues.
Autocheckpoint, synchronous and busy-timeout behaviour are unchanged, and migration checksums are unchanged, so existing databases open as before.
Tests check the linked SQLite version and every migration checksum.

The Rust toolchain moves from 1.92.0 to 1.94.1, so enclave image measurements change on real hardware.
The enclave does not link SQLite. Custom verifier enclaves do not need to rebuild for this release.
