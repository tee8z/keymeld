# KeyMeld 0.8.1 (beta)

This release updates the dependencies the cluster security review found below their fixed versions. No code, public API, gateway route, message layout or Cargo feature changes.

## Changes

- Lockfile updates: bytes to 1.12.1, rustls to 0.23.45, quinn-proto to 0.11.15, event-listener to 5.4.2, and the transitive rand 0.8 branch to 0.8.6. The event-listener update also removes concurrent-queue.
- Still present and noted: rsa 0.9.9 stays in the lockfile through optional sqlx-mysql dependencies with no active reverse path on Linux and no patched upstream version; the bincode and serde_cbor maintenance warnings need separate compatibility work.

## Upgrade

Point at the new tag:

```toml
keymeld-sdk = { git = "https://github.com/tee8z/keymeld", tag = "v0.8.1", features = ["client", "dlctix"] }
keymeld-core = { git = "https://github.com/tee8z/keymeld", tag = "v0.8.1" }
```

Rebuild enclave images from this tag; on Nitro that changes their measurements, so update any pinned PCRs before routing sessions to the new images. The gateway and enclaves can be upgraded independently of each other and of 0.8.0 peers. Rolling back to 0.8.0 is safe: states sealed under 0.8.1 use the same `escrow_state_v2` label.

## Beta status

This release retains the 0.4.0 beta limitations.
Validation uses simulated TCP enclaves and a mock KMS.
Real AWS Nitro hardware acceptance remains incomplete; use test keys and test funds only.
