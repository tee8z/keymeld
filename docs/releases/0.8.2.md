# KeyMeld 0.8.2 (beta)

The admin enclave cards now show enclave-reported sessions, observation time, connections, requests in flight, and transport failures.
Gateway-managed session counts are labeled separately. Confidential escrow work does not populate that session list.

Prometheus gains keymeld_enclave_public_info, keymeld_enclave_deployment_info, and keymeld_confidential_relay_total.
The gateway records existing public health responses and bounded relay outcomes for configured enclaves.
It does not inspect confidential payloads. An encrypted response does not prove successful signing or payment.

Optional KEYMELD_ENCLAVE_COMPONENT and KEYMELD_ENCLAVE_RELEASE values label the configured deployment.
These labels are operator declarations, not attested build measurements.
Stale enclave health becomes unknown. Native disclosures remain open until manual refresh.

No schema or wire-protocol changes are required. Existing coordinator verifier enclave binaries remain compatible.
Upgrade the gateway package; retain the deployed verifier and witness state. Rollback to gateway 0.8.1 remains compatible.
Validation uses unit tests, CI, and browser checks. Nitro hardware acceptance remains outside this change.
