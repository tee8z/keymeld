# KeyMeld v0.8.3

- The public enclave listing (`GET /api/v1/enclaves`) no longer publishes per-enclave session counts or uptime. Operators still see both on the enclave pages and in `keymeld_enclave_public_info`. The SDK has treated both fields as optional since #95, so clients built against it keep working.
- Slow-request warnings use a per-route threshold: 5 s for confidential relays, 1 s elsewhere, so normal relays no longer log WARN.
- New metrics: `keymeld_api_request_duration_seconds{endpoint,method}` and `keymeld_errors_total{kind}`.

Deploy after any coordinator that reads the listing is on an SDK with the optional fields (coordinator 2.18.1 or later). Includes #95 and #96.
