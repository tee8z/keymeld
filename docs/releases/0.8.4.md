# KeyMeld v0.8.4

Finished signing sessions expire after ten idle minutes. Inactive keygen families expire after 48 hours.
Authorized activity refreshes the parent session. Cleanup waits for in-flight commands and releases retained queue handles.

Per-kind and per-state session counts are logged once per minute without session identifiers.
Regression coverage includes restored signing after expiry and concurrent activity during cleanup.

Deploy the updated enclave binary as well as the gateway. Applications embedding the enclave must update their Keymeld source pin and rebuild.
Preserve sealed key material and durable confidential journals. This release does not change the wire protocol or sealed-state format.
