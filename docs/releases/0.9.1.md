# KeyMeld v0.9.1

The SDK's optional `dlctix` feature moves to dlctix 0.2, which adds optional anchor outputs and outcome-bound split transactions to DLC contracts.
Contracts built with both options off are unchanged, and contracts stored by dlctix 0.1.0 load unchanged.

The gateway, the enclaves, the wire protocol and the sealed-state format are unchanged.
Applications using the SDK's `dlctix` feature must update their Keymeld source pin and resolve dlctix 0.2 alongside it.
